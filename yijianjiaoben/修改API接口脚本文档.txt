一键修改 API 接口脚本及使用说明

一键修改 API 接口脚本
该脚本支持 Windows（批处理） 和 Linux/Mac（Shell），可一键修改项目中所有配置文件的 API 地址，适配本地开发、Vercel 部署等不同环境，无需手动逐个修改。
一、 功能说明
修改 vite.config.js 中的本地代理 target 地址
修改 api/proxy.js 中的服务端转发 baseUrl 地址
修改 test-api.bat/sh 中的测试 BASE_URL 地址
自动备份原配置文件（避免修改出错）
二、 Windows 版本 update-api.bat
bat
@echo off
chcp 65001 > nul
setlocal enabledelayedexpansion

echo ======================================
echo  《梦醒成空》播放器 - 一键修改 API 地址
echo ======================================

:: 1. 检查是否在项目根目录
if not exist "vite.config.js" (
    echo [错误] 未找到 vite.config.js，请在项目根目录运行此脚本！
    pause
    exit /b 1
)

if not exist "api\proxy.js" (
    echo [错误] 未找到 api\proxy.js，请在项目根目录运行此脚本！
    pause
    exit /b 1
)

:: 2. 输入新的 API 地址
set /p new_proxy=请输入本地代理目标地址（如 https://music.163.com/api）：
set /p new_baseurl=请输入服务端转发地址（如 https://music.163.com/api）：
set /p new_testurl=请输入测试接口地址（如 http://localhost:5173 或 https://xxx.vercel.app）：

:: 3. 备份原文件
echo [1/5] 备份原配置文件...
copy "vite.config.js" "vite.config.bak" > nul
copy "api\proxy.js" "api\proxy.bak" > nul
if exist "test-api.bat" copy "test-api.bat" "test-api.bak" > nul

:: 4. 修改 vite.config.js 中的 proxy target
echo [2/5] 修改 vite.config.js 本地代理地址...
powershell -Command "(Get-Content vite.config.js) -replace 'target: ''[^'']*''', 'target: ''!new_proxy!''' | Set-Content vite.config.js"

:: 5. 修改 api/proxy.js 中的 baseUrl
echo [3/5] 修改 api/proxy.js 服务端转发地址...
powershell -Command "(Get-Content api\proxy.js) -replace 'const baseUrl = ''[^'']*''', 'const baseUrl = ''!new_baseurl!''' | Set-Content api\proxy.js"

:: 6. 修改 test-api.bat 中的 BASE_URL（如果存在）
if exist "test-api.bat" (
    echo [4/5] 修改 test-api.bat 测试地址...
    powershell -Command "(Get-Content test-api.bat) -replace 'const BASE_URL = ''[^'']*''', 'const BASE_URL = ''!new_testurl!''' | Set-Content test-api.bat"
)

:: 7. 完成提示
echo [5/5] 所有 API 地址修改完成！
echo - 本地代理地址：!new_proxy!
echo - 服务端转发地址：!new_baseurl!
echo - 测试接口地址：!new_testurl!
echo - 原文件已备份为 .bak 后缀
echo ======================================

pause
三、 Linux/Mac 版本 update-api.sh
bash
#!/bin/bash
set -e

echo "======================================"
echo " 《梦醒成空》播放器 - 一键修改 API 地址"
echo "======================================"

# 1. 检查是否在项目根目录
if [ ! -f "vite.config.js" ]; then
    echo "[错误] 未找到 vite.config.js，请在项目根目录运行此脚本！"
    exit 1
fi

if [ ! -f "api/proxy.js" ]; then
    echo "[错误] 未找到 api/proxy.js，请在项目根目录运行此脚本！"
    exit 1
fi

# 2. 输入新的 API 地址
read -p "请输入本地代理目标地址（如 https://music.163.com/api）：" new_proxy
read -p "请输入服务端转发地址（如 https://music.163.com/api）：" new_baseurl
read -p "请输入测试接口地址（如 http://localhost:5173 或 https://xxx.vercel.app）：" new_testurl

# 3. 备份原文件
echo "[1/5] 备份原配置文件..."
cp -f "vite.config.js" "vite.config.bak"
cp -f "api/proxy.js" "api/proxy.bak"
if [ -f "test-api.sh" ]; then
    cp -f "test-api.sh" "test-api.bak"
fi

# 4. 修改 vite.config.js 中的 proxy target
echo "[2/5] 修改 vite.config.js 本地代理地址..."
sed -i "" "s/target: '[^']*'/target: '$new_proxy'/g" vite.config.js

# 5. 修改 api/proxy.js 中的 baseUrl
echo "[3/5] 修改 api/proxy.js 服务端转发地址..."
sed -i "" "s/const baseUrl = '[^']*'/const baseUrl = '$new_baseurl'/g" api/proxy.js

# 6. 修改 test-api.sh 中的 BASE_URL（如果存在）
if [ -f "test-api.sh" ]; then
    echo "[4/5] 修改 test-api.sh 测试地址..."
    sed -i "" "s/const BASE_URL = '[^']*'/const BASE_URL = '$new_testurl'/g" test-api.sh
fi

# 7. 完成提示
echo "[5/5] 所有 API 地址修改完成！"
echo "- 本地代理地址：$new_proxy"
echo "- 服务端转发地址：$new_baseurl"
echo "- 测试接口地址：$new_testurl"
echo "- 原文件已备份为 .bak 后缀"
echo "======================================"
四、 使用说明
保存脚本
Windows：将代码复制到记事本，保存为 update-api.bat，放入项目根目录
Linux/Mac：将代码复制到文本编辑器，保存为 update-api.sh，放入项目根目录
赋予权限（仅 Linux/Mac）打开终端，进入项目根目录，执行命令：
bash
chmod +x update-api.sh
运行脚本
Windows：双击 update-api.bat，按提示输入 3 个地址
Linux/Mac：终端执行 ./update-api.sh，按提示输入 3 个地址
默认地址参考
地址类型	默认值	说明
本地代理目标地址	https://music.163.com/api	网易云音乐官方 API 地址
服务端转发地址	https://music.163.com/api	同本地代理目标地址
测试接口地址	http://localhost:5173	本地开发测试地址
五、 注意事项
脚本会自动备份原配置文件（后缀 .bak），若修改出错可删除新文件，将 .bak 后缀去掉恢复。
输入地址时不要带引号，直接输入完整 URL 即可。
确保运行脚本时处于项目根目录，否则会提示找不到文件。
